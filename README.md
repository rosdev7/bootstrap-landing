# Nova Studio — Bootstrap 5 Landing Page

Landing page responsive dựng bằng **Bootstrap 5**, minh hoạ kỹ năng chuyển đổi thiết kế sang giao diện web chuẩn responsive.

🔗 **Demo:** https://rosdev7.github.io/bootstrap-landing/

## Công nghệ
- Bootstrap 5.3 (grid, navbar, cards, carousel, pricing, form)
- Bootstrap Icons
- HTML5 / CSS3 / JavaScript (ES6)

## Thành phần minh hoạ
- Navbar responsive (collapse trên mobile)
- Hero section 2 cột với lưới Bootstrap
- Lưới card dịch vụ (responsive `col-md` / `col-lg`)
- Carousel đánh giá khách hàng
- Bảng giá 3 gói
- Form liên hệ có **validation** của Bootstrap
- Footer responsive

## Chạy thử
Mở trực tiếp `index.html` bằng trình duyệt, hoặc xem bản demo online ở link phía trên.
